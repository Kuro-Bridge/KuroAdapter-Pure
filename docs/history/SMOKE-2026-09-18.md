## 7. 残留与注意

- `hello_ack.serverId` 常量 `kurobridge-pure`（本轮真机再次确认上报值，配置化随第 5 条）；
- **动态端口坑**：`ws` 段缺省 = 动态端口 + 全部接口，对端互联必固定 `ws.port`
  （本沙盒固定 25580，README 已有同款提示）；
- mock-inject UNIQUE 冲突复现与处置建议（清 `koishi-dev/data/koishi.db` 的 mock binding
  行后重跑，属 koishi-dev 沙盒自愈范畴）；
- koishi `bun run start` 是进程树（bun → koishi.exe → bun）：只杀外层 bun 会自动重启
  （20:38:05 实测自愈重连成功），收尾须 `taskkill /T` 整树；
- Paper 首启需 paperclip 下载 vanilla jar，本机网络不可达时从既有沙盒拷 `cache/` +
  `libraries/` 即离线可用；
- Paper 无 stdin 管道时无法发 `stop`：优雅停用须以 `tail -f cmd.in | java …` 方式起
  （本轮二轮即此法，`echo stop > cmd.in` 触发，见 console-stop.log 20:40:03
  `Stopping the server` → `[KuroBridgePure] Disabling KuroBridgePure v0.1.0`）。
