# 历史册归档（docs/history/）

> 本目录为**历史存档**：各册成文即冻结，**正文一律不改写**（含笔误与过时结论）。
> 事实后续变化一律以**追加式勾账补注**登记（唯一合法变更形态；样板 =
> `SMOKE-2026-09-18-2.md` §6 各条〔2026-09-19 勾账：…〕，bcdf0a9），格式：
>
>   〔YYYY-MM-DD 勾账：<结论一句话>（出处册/commit）〕
>
> 插在被勾账条目之后，不得删改原文。若复核发现原文记录有误（如 SMOKE-2 §6-2 的
> f1649a0 整段替换属违规先例，特此立规杜绝），**保留原文**，在其后追加：
>
>   〔YYYY-MM-DD 复核更正：原文「<误>」应为「<对>」，详见 <commit>〕
>
> 禁止整段替换或删除原文。现状速查与勾账入口：[`../STATUS.md`](../STATUS.md)。
